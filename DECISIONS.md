# Architecture decisions

## MVP storage
- Video and extracted-audio objects live in a private Supabase Storage bucket named `captions-media`.
- Object keys are generated by the API; never trust client filenames as object paths.
- The bucket is private. Media is streamed through the API after server-side project/key validation, so service credentials stay on the backend.
- Supabase PostgreSQL stores project metadata and caption JSON through Prisma.
- Local files are not the source of truth for uploaded media.

## Jobs and processing
- Redis + BullMQ run transcription jobs.
- The API process can run the queue worker in the same process for simple local development; production can split it into a separate worker process.
- FFmpeg and ffprobe must be installed on the machine running the worker.
- OpenAI Whisper is the default transcription provider, behind an interface.

## Development conventions
- Preserve the repository's existing npm workspaces rather than switching package managers.
- No authentication is included in this MVP. Do not treat it as production-safe for multiple untrusted users until ownership/auth checks are implemented.
- Keep provider and storage interfaces replaceable.
